# Bijdragen aan de Verzuimstandaard

SIVI beheert de Verzuimstandaard.

## Vragen

Heb je een vraag over de Verzuimstandaard? Dien dan centraal een **Vraag over de Verzuimstandaard** in.

SIVI beantwoordt je vraag.

## Wijzigingsverzoeken

Iedereen kan een wijzigingsverzoek indienen.

Gebruik hiervoor het formulier **Wijzigingsverzoek**.

De inhoudelijke behandeling en besluitvorming vindt niet in GitHub plaats, maar binnen de daarvoor ingerichte SIVI-werkgroepen.

We kunnen in GitHub je verzoek registreren en erover communiceren.

## Wijzigingen in de standaard

Alleen SIVI wijzigt de officiële Verzuimstandaard.

Je kunt wijzigingsvoorstellen indienen via Issues. Pull requests nemen we niet in behandeling.

## Vertrouwelijke gegevens

Plaats geen persoonsgegevens, medische gegevens, bedrijfsvertrouwelijke informatie of andere vertrouwelijke gegevens in Issues of Discussions.
